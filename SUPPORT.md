# Support · 使用支持

Read the troubleshooting table in [English](README.md#upgrade-uninstall-and-troubleshooting)
or [中文](README.zh-CN.md#升级卸载与排查), then use
[GitHub Issues](https://github.com/boomkalakasha/codex-model-radar-plugin/issues)
for reproducible plugin problems.

Include the plugin version, Codex native CLI version, Node version and the
visible error. Share redacted screenshots or synthetic reproductions. Never
upload `runtime.json`, a Codex home or configuration backups.

这是社区项目，没有响应时限承诺。原站数据或评测问题请回到
[Codex 雷达](https://codexradar.com/) 核对；本项目不代表来源站点或 OpenAI。

Windows is the currently tested installation platform. Security issues use
the private reporting route in SECURITY.md.
