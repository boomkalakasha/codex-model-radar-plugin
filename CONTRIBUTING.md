# Contributing · 参与贡献

Open an issue describing the observed behavior, expected result, Codex/Node
versions and a minimal reproduction. Use synthetic examples and redact paths,
tokens and account details. Do not attach Codex profiles or runtime files.

For code changes, create a focused branch and pull request. Run `npm ci`,
`npm run build` and `npm test`; include the relevant result in the PR. Keep
the Chinese and English user guides aligned when behavior changes.

提交前说明实际问题、预期行为及验证结果；不上传真实账号、配置备份或运行令牌。
保持数据署名，测试使用合成数据。提交标题采用 Conventional Commits。

Contributions must be yours to submit under Apache-2.0. Third-party assets
need their own provenance and license information. Security reports belong in
the private channel described in SECURITY.md.
